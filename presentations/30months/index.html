Automatic Lyrics Transcription from Single Audio Channel Homophonic Music Recordings
Gerardo Roa Dabike

The Task

To recognise sung speech from an accompaniment singing.

Breaking down the task

The project was split into three components or stages.

  1. Unaccompanied singing recognition.
  2. Audio source separation and singer enhancement.
  3. Jointly optimise the singer enhancement with the acoustic model

Stage 1

Considered a complete stage!

  • Two papers
    • Automatic Lyric Transcription from Karaoke Vocal Tracks: Resources and a Baseline System (Interspeech 2019).
    • The Use of Voice Source Features for Sung Speech Recognition (to be submitted ICASSP 2021).
P1
- Present a baseline for English spoken sung recognition task.
- Processing step to use Sing!300x30x2 Dataset for ASR. Including alignment, segmentation
- Human annotators correct the alignment timings and re-transcribe the speech.
P2
- Presents performances using voice source features
- Pitch may help to improve voiced/unvoiced and vowels sounds discrimination, normalise for different speakers
- Jitter, shimmer and HNR are associated with speaker identity may improve speaker normalisation.
- This was the first study using this features on a large sung speech data.
- Only beneficial for small size data.

Stage 2

Model Architecture

TasNet = Deep LSTM network plus fully connected with softmask for mask generation
ConvTasNet = Temporal Convolutional Network as replacement of RNNs for sequence modelling tasks
Series of stacked 1D dilated convolutional blocks with increased dilation factors.
M convolutional blocks are then repeated R times.
